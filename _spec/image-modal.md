# Feature: image modal

## Goal

The goal is this feature is to elevate user experience by preventing full-size images opening in new tab.

## Requirements

- no dependencies or single dependency that delivers the goal
- no significant change to existing code, preferably no change needed to existing anchors in the posts
- modal should have a close button, e.g. a cross in the upper right corner
- design of the cross should follow the colours and the existing colours of the website, either blue, black or white

### Interaction

If there is an image inside the achor tag that links to the original full-size image, clicking on the image should open a modal with the full-size image
