# New pagination design feature

The goal of this feature is to implement the new design of pagination given the design in `revised-pagination-design.png`

## Requirements

- no added dependencies
- no added front end libraries
- no new colours or images for the pagination
- no change in page layout or style that affects either list of the posts, the header or the footer of the website
- no rounded corners, keep rectangular design
- contrast and size that is UX-friendly incl. a11y considerations
- pagination bar should be as wide as the content above, e.g. on front page
- pagination elements should remain subtle and not out of proprotion, as depicted on the PNG

### Interaction

- bold underline should be displayed when hovering
- hovered item should be similar to the active item, but bold underline should be lost when moving out of focus
- no underline should appear on Prev/Next buttons
