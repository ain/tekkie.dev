> macOS is the operating system that powers [Apple](/apple)'s Mac computers, including the [MacBook](/macbook) line. Built on the Unix-based Darwin foundation, it pairs a proprietary desktop environment with a POSIX command line underneath.

The Unix underpinnings are exactly why macOS has stayed my daily driver: the same machine runs a polished desktop and the shell tooling I actually work in. The friction tends to live in the seams between those two worlds — a `free -m` that does not exist, a pasteboard that stops talking to Vim inside tmux, a modifier key that Apple decided you did not need remapped.

Please find selected macOS posts below. Topics vary from DMG disk images and command line workarounds to keyboard remapping and small desktop utilities.
