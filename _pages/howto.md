> A how-to is an informal, step-by-step guide that walks through a specific task from start to finish. Unlike reference documentation, it is organised around a goal rather than a feature set: one problem, one path to solving it.

Most of these started as something I had to work out once and did not fancy working out a second time. The posts that end up here are the ones where the official documentation stopped just short of the actual problem — a tool that assumes a setup you do not have, or a fix that only makes sense after you know which of the moving parts is at fault.

Please find selected how-to posts below. Topics vary from [macOS](/macos) keyboard remapping and terminal tooling to build status badges and [DevOps](/devops) pipeline setup.
